## Project Overview

This project is an earlier portfolio implementation built around a multi-page static website. It includes dedicated sections for work, about information, and contact details, with styling authored in SCSS and compiled to CSS.

## Pages

- Home
- Work
- About
- Contact

## Tech Stack

- HTML5
- SCSS / CSS
- JavaScript
- Node Sass

## Repository Structure

- `dist/` — compiled, browser-ready website files
- `scss/` — source stylesheets
- `package.json` — development tooling configuration
- `.github/workflows/` — automatic publishing to the `gh-pages` branch
